# Programmer 2: DDROID status page

A small, self-contained browser prototype for the Programmer 2 assignment: show water level, pump state, and livestock location status using sample values.

## Open it

Open `index.html` in a web browser. It does not need Node.js, Node-RED, an internet connection, or extra packages.

## Try the sample controls

- **Simulate LOW water** sets the trough to 22% and switches the simulated pump ON.
- **Simulate FULL tank** sets the level to 100% and switches the simulated pump OFF.
- **Move cow sample** alternates Cow 001 between Paddock East and Paddock West.
- **Reset sample** restores the initial values.

All readings are demonstration values stored in the browser page. This prototype is not connected to a real pump, water sensor, GPS tracker, cow, or backend. The buttons do not control physical equipment.
